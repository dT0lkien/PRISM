# Prism для Android

Android-клиент Prism использует системный VPN-интерфейс и ядро sing-box 1.13.15. Интерфейс написан на Kotlin и Jetpack Compose. В приложении используется тёмное оформление.

## Подключение

1. Установите `app/build/outputs/apk/debug/app-debug.apk` на ARM64-устройство с Android 8.0 или новее. Для импорта конфигурации требуется актуальный системный Android WebView.
2. Нажмите **Добавить сервер** и вставьте ссылку на сервер либо HTTPS-адрес подписки. Поддерживаются, в частности, VLESS, VMess, Shadowsocks, Trojan, Hysteria2 и TUIC. Подписки могут содержать список ссылок, base64, Clash YAML или sing-box JSON.
3. Выберите сервер или **Автовыбор** в списке и включите тумблер VPN. При первом подключении подтвердите системный запрос Android.

Для подключения нужны данные рабочего сервера. В приложении можно переключать режим маршрутизации, управлять правилами и DNS, просматривать журнал. Изменения конфигурации применяются после переподключения.

## Пинг серверов

Выберите **TCP** или **URL** на странице **Серверы** и нажмите значок молнии. TCP показывает время установления TCP-соединения с адресом и портом сервера. URL отправляет запрос к `https://www.gstatic.com/generate_204` через каждый сервер с его настройками протокола. Результаты отображаются рядом с серверами. Удерживайте строку сервера, чтобы открыть меню удаления. Выбор нового сервера во время работы VPN применяется после переподключения.

## Быстрые настройки Android

Добавьте плитку **Prism VPN** через **Настройки → Добавить плитку VPN** на Android 13 и новее или через редактирование плиток в системной шторке.

После первого подключения плитка включает и выключает VPN прямо в шторке. Если конфигурация изменилась или нужно выдать разрешение Android, плитка откроет Prism и продолжит подключение там. При первом использовании без сервера Prism предложит добавить его. Автозапуск при перезагрузке использует конфигурацию последнего подключения, если она соответствует текущим настройкам и версии приложения.

## Маршрутизация через JSON

Перейдите свайпом или нажмите **Маршруты** на главном экране, затем откройте **Редактор JSON**. Редактор принимает объект с секцией `route`. Через меню можно загрузить эту секцию из локального файла, экспортировать черновик или вставить пример.

```json
{
  "route": {
    "rules": [
      { "domain_suffix": ["example.org"], "action": "route", "outbound": "direct" },
      { "ip_cidr": ["203.0.113.0/24"], "action": "reject" }
    ],
    "final": "proxy"
  }
}
```

Режим **Умный** использует встроенные пресеты. Режим **Из конфига** применяет `route.rules` после обнаружения протокола и перехвата DNS. Режим **Всё через туннель** направляет трафик к выбранному серверу без правил обхода. Сохранение непустой секции `route` выбирает режим **Из конфига**. `route.final` задаёт маршрут для трафика, который не совпал с правилами. Записи `route.rule_set` позволяют объявить наборы правил для своей конфигурации. `proxy` означает выбранный сервер, `direct` — прямой выход, `auto` доступен после импорта серверов.

Нажмите **Итог**, чтобы увидеть собранную секцию, или **Проверить и сохранить**, чтобы проверить конфигурацию ядром и сохранить правки. Переподключите VPN вручную для применения. Чтобы удалить пользовательские правила, сохраните `{"route":{}}`. Для возврата к пресетам выберите **Умный**. Описание полей доступно в [документации sing-box 1.13.15](https://github.com/SagerNet/sing-box/tree/v1.13.15/docs/configuration/route).

## Сборка на этом Mac

Из корня репозитория выполните:

```sh
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"

sh scripts/build-libbox-android.sh
cd android
./gradlew :app:assembleDebug :app:lintDebug
```

Для сборки нужны Android SDK 35, NDK 28.2.13676358, JDK 17 или новее и Go. Gradle подписывает отладочный APK стандартным debug-ключом. Отладочная сборка использует пакет `com.prism.vpn.debug` и устанавливается отдельно от `com.prism.vpn`.

После изменений в общем TypeScript-коде пересоберите Android-бандл из корня репозитория:

```sh
npm ci
node scripts/build-android-shared.mjs
```

Для релизной сборки Gradle читает `storeFile`, `storePassword`, `keyAlias` и `keyPassword` из локального `android/keystore.properties`. Файл и ключ исключены из Git.
